# Titanic EDA Project

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python, Pandas, Matplotlib, and Seaborn.

The goal is to understand passenger demographics and identify factors that influenced survival.

---

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn

---

## Analysis Performed

- Data cleaning
- Missing value analysis
- Survival distribution
- Age distribution
- Fare distribution
- Correlation analysis
- Passenger class analysis
- Gender-based survival analysis

---

## Key Insights

- Female passengers had significantly higher survival rates.
- First-class passengers survived more frequently.
- Younger passengers showed better survival chances.
- Passenger fare was positively associated with survival.

---

## Dataset

Built-in Titanic dataset from Seaborn.
